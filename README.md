# Quicksense Dashboard

Single-file dashboard (`index.html`) for QuicksenseGoated.

## Run on localhost

```bash
npm run dev
```

Open:

- Home: http://localhost:3000/
- Clip of the Week: http://localhost:3000/#cow

No install step — `npm run dev` uses `npx serve` on port **3000**.

## Deploy

Push to `main`. GitHub Pages serves from the repo root:

https://quicksensegoated.github.io/Quicksense-Dashboard/

## Workflow

Edit `index.html` → test on localhost → commit and push to `main` (no PRs).
